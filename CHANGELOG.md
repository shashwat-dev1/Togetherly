## [0.1.0-alpha] - 2026-11-16
### Added
- Initialized Expo SDK 58 project with TypeScript strict mode and Expo Router.
- Configured Git version control.
- Created core architecture and system specifications:
  - `PROJECT_STATUS.md`
  - `TECHNICAL_ARCHITECTURE.md`
  - `DATABASE_SCHEMA.md`
  - `IMPLEMENTATION_ROADMAP.md`
  - `CHANGELOG.md`
  - `TESTING.md`
- Designed centralized Design Token system (`src/constants/tokens.ts`) with romantic, mature color palette (Lavender `#9275E8`, Coral `#FFB5A7`, Cream `#FFF9F5`).
- Initialized core component library architecture (`AppButton`, `GameCard`, `CoupleAvatar`, `Modal`, `Toast`).
- Configured Firebase client service architecture with offline/mock mode for reliable local development without hardcoded secrets.
